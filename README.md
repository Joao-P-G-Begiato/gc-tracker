# GC Tracker

Controle de personagens do **Grand Chase Classic** da guilda AntiSociais.

- Site: https://joao-p-g-begiato.github.io/gc-tracker/
- Login com conta Google; dados no Firebase (Firestore).
- `index.html`: o sistema inteiro (HTML + CSS + JS, sem build).
- `icons/`: ícones dos personagens (`<id>.webp`).
- `firestore.rules`: regras de segurança do banco (colar em Firestore → Regras).
